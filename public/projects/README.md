# Imagens dos Projetos

Esta pasta contém as imagens de prévia (thumbnails) dos seus projetos para o portfólio.

## Estrutura esperada

Adicione os arquivos de imagem nesta pasta com os seguintes nomes:

- `bewear.jpg` - Bewear Bootcamp
- `ecommerce-sandalias.jpg` - Ecommerce Sandalias
- `e-contract.jpg` - e-Contract
- `clinica-saude.jpg` - Clínica Saúde
- `moreilandia.jpg` - Moreilandia

## Dimensões recomendadas

- **Resolução**: 800x600px ou similar (proporção 4:3)
- **Formato**: JPG ou PNG
- **Tamanho**: Máximo 300KB por imagem para melhor performance
- **Otimização**: Use ferramentas como TinyPNG ou ImageOptim para comprimir

## Como adicionar

1. Capture ou crie uma prévia do seu projeto (screenshot, mockup, etc.)
2. Otimize a imagem
3. Renomeie com o slug do projeto (exemplo: `bewear.jpg`)
4. Coloque na pasta `/public/projects/`

## Resultado

As imagens aparecerão automaticamente nos cards dos projetos na seção "Projetos" do seu portfólio, com efeito hover elegante de zoom.

---

**Nota**: O Next.js Image otimiza automaticamente as imagens, servindo diferentes formatos e tamanhos conforme o dispositivo.
